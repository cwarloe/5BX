## In-Flow identity transfer: verified procedure (video #10 completed)

1. Open the successful sit-up video 08 in Flow; seek ~2.10 seconds, when the boy's face and outfit are clearly visible.
2. Select **Save frame** in the video player. Flow creates a native image asset in the same project.
3. Edit this saved still using Nano Banana 2.1 to change **only the posture** to a true kneeling push-up UP position. Preserve the blue tank, charcoal shorts, hair, face, normal youth build, shoes, track and camera. A native edited still was successfully generated (Flow stated 0 credits).
4. In the project chat, **Add ingredient → image**, choose the edited native asset, and verify that the attachment thumbnail visibly shows the boy in the kneeling-UP pose.
5. Ask for one Omni 1.2 Flash 6-second UP→DOWN→UP push-up video. Flow quoted 18 credits; a one-time approval was given. **Video #10 rendered and sampled; human approval remains pending.**

**Critical lesson:** Flow's agent cannot turn a Google Drive URL pasted in chat into an actual attached frame. The file picker initially could not access our scratch/Drive asset; subsequent verified direct Flow MP4 download and workspace import is documented separately in the playbook. Saving a frame from a video *inside Flow* and transforming that native image bypasses the transfer barrier. Keep the newer four-frame external card separately as pose QA, not as the rendered video's source.
