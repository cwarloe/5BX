**Open gates before production:** (1) one normal-speed motion/loop test to establish heel lift and return cadence rather than a jump/crossfade; (2) independent biomechanics judgment on A/D knee depth and B transition; (3) identity/camera lock with approved v2 across chart, not just this card. Do not blindly animate from all four independent reference tiles; select one valid starting frame and constrain the actual movement.

**Process lesson:** repeated explicit wording of “heel raise” was insufficient in a jointly generated 2×2; a one-variable footwear edit made it visible. Strict 5BX text then revealed a subtler problem—the knee bend was too shallow. Even the 28C correction retained ~135–145° geometry, so an independent challenge and more concrete pelvis/hip-to-knee angle language were needed for 28D. It is markedly closer to 110° while retaining the heel-only lift. Keep failed versions and exact prompts rather than polishing only the final photograph; all joint-angle estimates remain **2D visual projections**, not a measured skeleton.
