## What this test taught us

1. A **single vetted start photo** can produce full cycles in Flow's Omni 1.2 Flash, not only a one-way motion. Explicitly requesting a complete six-second cycle and the identical final posture appears promising, especially for the sit-up that previously stopped at the reach. This is an inference from these two generated examples, not a guarantee for every exercise.
2. A single **full card** remains best for developing pose geometry and character consistency, but the **video generator only gets its one start frame**. This avoids 3-image order reversal and ghosting risk.
3. The older green-shirt image retains a slightly athletic arm/hair style, despite a soft-youth prompt. To test the latest identity standard, upload the **new 05/06 start frames** (Drive IDs and links in folder index) into Flow and repeat with the same prompt, *one variable changed: visual identity anchor*.
4. Exact side profile helped knee supports, while slight oblique view helped the sit-up show both straight legs. No body-length or extreme-flexibility corrections were required.
5. **Do not silently promote** these to approved Mixer clips: first obtain Charles's judgment, watch motion at normal speed and keyframes, check frame-to-frame continuity, and arrange actual MP4 transfer to the Drive review folder.
